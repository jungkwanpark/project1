파이썬 앱을 개발하려고 합니다. (파일 경로/이름/확장자 : /project/app.py)

 - Input : 미국 주식 티커명 입력
 - Output : 아래 4가지 웹사이트 API 또는 크롤링을 통해, Input 입력받은 종목에 대한 종합적인 분석을 제시해주는 AI Agent (RAG 기반) 
 - RAG 기반 소스데이터 : 아래 3가지 정보를, 아래 웹사이트 API 에서 확인

------------------------------------------------------------------------------------------------------
(1) 핀비즈 (티커명 변수 기반 홈페이지 주소) --> 해당 티커 종목의 실시간 P/E 정보 확인
  - https://finviz.com/quote.ashx?t=PLTR
  - https://finviz.com/quote.ashx?t=CRM
  - https://finviz.com/quote.ashx?t=RXRX

(2) 네이버페이 (티커명 변수 기반 홈페이지 주소) --> 
  - 손익계산서 (티커명 변수 기반 손익계산서 정보 확인) --> 매출액, 영업이익, 순이익 추세 확인 (그래프) 
       - https://m.stock.naver.com/worldstock/stock/PLTR.O/finance/income/annual
       - https://m.stock.naver.com/worldstock/stock/CRM.O/finance/income/annual
       - https://m.stock.naver.com/worldstock/stock/RXRX.O/finance/income/annual

  - 현금흐름표 (티커명 변수 기반 현금흐름표 정보 확인) --> 영업활동현금흐름 추세 확인 (그래프)
       - https://m.stock.naver.com/worldstock/stock/PLTR.O/finance/cash/annual
       - https://m.stock.naver.com/worldstock/stock/CRM.O/finance/cash/annual
       - https://m.stock.naver.com/worldstock/stock/RXRX.O/finance/cash/annual

  - 대차대조표 (티커명 변수 기반 대차대조표 정보 확인) --> 부채/자본 비율 확인
       - https://m.stock.naver.com/worldstock/stock/PLTR.O/finance/balance/annual
       - https://m.stock.naver.com/worldstock/stock/CRM.O/finance/balance/annual
       - https://m.stock.naver.com/worldstock/stock/RXRX.O/finance/balance/annual

(3) 웨일즈위스덤 (티커명 변수 기반 홈페이지 주소) -->  Vanguard, BlackRock, State Street 3대 기관투자자의 매수/매도 동향 확인
  - https://whalewisdom.com/stock/pltr 
  - https://whalewisdom.com/stock/crm 
  - https://whalewisdom.com/stock/rxrx
